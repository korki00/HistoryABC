Privacy Policy

Last updated: 15 November 2026

1. Who we are

HistoryABC Tools is a private script used only by the owner of the YouTube channel HistoryABC to manage that channel. Contact: korki42@gmail.com.

2. YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data is accessed

After the channel owner signs in with Google (OAuth 2.0), the tool accesses only the owner's own channel:

  • the owner's videos and playlists (to upload and schedule videos and add them to playlists),
  • view counts and YouTube Analytics metrics of the owner's own videos (views, average view duration, average view percentage).

No data of other users, viewers or channels is collected. No personal data of viewers is accessed.

4. How the data is used and stored

  • The data is used only to upload/schedule the owner's videos and to create a private daily statistics report for the owner.
  • It is stored only locally on the owner's computer (a JSON log file). The OAuth token is stored locally and never shared.
  • No data is sold, shared with third parties, or shown publicly.
  • No cookies or tracking are used by the tool or this website.

5. Retention and deletion

Statistics are refreshed daily. Data obtained from YouTube API Services is deleted or refreshed within 30 days, except aggregated view numbers of the owner's own videos, which are kept for the owner's own comparison. The owner can delete all stored data at any time by deleting the local files.

6. Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revoking, the tool can no longer access the channel, and the stored token stops working.

7. Changes

If this policy changes, the new version is published on this page with a new date.
